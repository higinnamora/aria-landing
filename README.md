# ARIA Landing

Landing page de ARIA creada solo con HTML y CSS. Presenta el producto, sus funciones, ventajas, planes y enlaces de contacto por WhatsApp.

## Vista local

Abre `dist/index.html` en el navegador o sirve la carpeta `dist` con un servidor estático.

## Contenido

- `dist/index.html`: estructura y contenido.
- `dist/styles.css`: diseño adaptable.
- `index.html`: entrada de GitHub Pages en la raíz. Es una copia de `dist/index.html` con la ruta de estilos ajustada a `dist/styles.css`.

GitHub Pages publica desde `main` y `/(root)`. Al cambiar la landing, actualiza `dist/index.html` y su copia de la raíz antes de subir los cambios.
